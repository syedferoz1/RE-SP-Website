# Contributing to RE-SP-Website

Thank you for your interest in contributing. Please follow these guidelines:

- Fork the repository and create a feature branch `feature/your-feature`.
- Keep changes small and focused.
- Follow existing code style (Tailwind utility classes, semantic HTML).
- Test changes locally before submitting a PR.
- Include descriptive commit messages.
- For significant changes, open an issue first to discuss the design.

Running locally:

1. Serve the files using a simple static server:

```bash
# Using Python 3
python -m http.server 8000
```

2. Open `http://localhost:8000` and verify the site.

Accessibility and testing:
- Ensure forms are accessible and keyboard-navigable.
- Add unit tests or integration tests where possible.

Thank you!"
